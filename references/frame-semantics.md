# 帧语义与动作连贯性约束（防突变规范）

本文件是逐格提示词的**语义基准**。图像模型最容易犯的错不是画得不像，而是 26 格之间
左右脚互换、视角跳变、趾数变化、污渍忽有忽无、表情变成另一张脸。以下约束必须原样并入
每一条生成提示词，并在生成后逐条复核。

## 1. 前爪 6 帧：同一只脚的一次完整下落

定义一只**固定的脚**（例如：角色自己的左脚，脚尖朝画面左侧），全部 6 帧必须是这只脚在
同一条时间线上的连续姿态，不是 6 张不同的脚。

| 帧 | 姿态 | 允许的变化 |
|---|---|---|
| `front_0` | 侧视、脚跟抬起、脚掌离地最高，脚尖朝左；能看到脚底边缘 | 基准帧 |
| `front_1` | 同一只脚下落，脚掌转向观众（可见脚底/脚趾），略低于帧 0 | 只增加旋转/高度变化 |
| `front_2` | 继续下落，脚掌更正对观众、更接近地面 | 只继续同一方向的旋转 |
| `front_3` | 已触地，转为正面/俯视压平的脚，脚趾朝左，轮廓最舒展 | 触地压平 |
| `front_4` | 同一只脚继续加压，脚掌更扁、趾端更贴地 | 只增加压扁程度 |
| `front_5` | 最大压力，脚掌最扁，趾缘/脚底出现最多污渍 | 只增加污渍与压扁 |

## 2. 后爪 5 帧：同一双脚的另一只（远景）

`back_0..4` 是**同一只后脚**随压力递增的 5 个状态：从不施压到完全压实。
与前爪共享：左右约定、趾数、趾形、指甲/爪垫形状、毛色/肤色、花纹、光照方向、线条粗细。
差异只允许：透视略小、略淡（远景），以及随压力单调增加的压扁与污渍。

## 3. 表情 14 帧：同一张脸，只动眉眼嘴

| 组 | 语义 |
|---|---|
| `normal_0` | 最低 ego：平静/略困/无情绪 |
| `normal_1` | 略微注意 |
| `normal_2` | 轻度兴趣、嘴角微扬 |
| `normal_3` | 愉悦、眼睛更亮 |
| `normal_4` | 明显满足、得意 |
| `normal_5` | 最高 ego：陶醉/眯眼满足 |
| `excite_0..5` | 与 `normal_0..5` **一一对应**：同一 ego 等级、同一张脸，只是"刚获得 ego / 兴奋"版本：眼睛更睁大、眉毛上扬、脸颊泛红、嘴更张开；不得改成另一套五官 |
| `tired_0` / `tired_1` | 体力耗尽的两帧交替：疲惫、喘气、半睁眼；两帧之间只允许**眨眼/嘴部幅度/头部位移几像素**的微小差别，不得换表情、换角度 |

`endscreen`：256×128 横幅，画角色与小人（tinies）的收尾画面，作为结算页顶部图；
可以有背景（此格允许不透明），但不得含文字、边框、UI。

## 4. 连贯性硬约束（必须写进每条提示词）

- **C1 同一只脚**：26 格中脚的左右、趾数、趾序、爪垫/指甲形状、饰品、疤记、配色、线宽、阴影方向全部固定。禁止左右翻转、禁止换脚、禁止增删脚趾。
- **C2 视角单调**：前爪 0→2 是"抬起→转掌→下落"，3→5 是"触地→加压→最大压力"。禁止在序列中途从侧视突然跳成俯视再跳回；后爪同理。
- **C3 压力单调**：压扁程度、污渍/贴纸数量与面积随帧号**只增不减**。禁止污渍在低压力帧出现、高压力帧消失。
- **C4 姿态幅度递减**：相邻两帧的姿态差应小且方向一致；不得出现"前爪帧 2 还是脚底朝上、帧 3 突然变成侧面全脚掌"这类断崖。
- **C5 前后爪同源**：后爪必须与前爪像是同一角色身上的另一只脚，不得换成兽蹄/鞋/手/另一物种。
- **C6 表情只动眉眼嘴**：耳形、脸型、发型、瞳色、项圈、斑点、妆容固定。禁止换头、换角度、换画风。
- **C7 excite 与 normal 成对**：`excite_N` 必须是 `normal_N` 的"同一时刻更兴奋"，不是重新画一张脸。
- **C8 tired 两帧微差**：只允许眨眼级差异，禁止突变。
- **C9 透明与边界**：每格透明背景（或纯色底由脚本去背）、主体居中、不越格、不画边框/文字/投影/背景板。
- **C10 手不能当脚**：若用户只提供了手部参考图，仅可借用线条、配色、指甲/饰物风格；脚的解剖结构以示例 11 帧与用户文字描述为准，不得把手掌直接画成脚。

## 5. 生成策略（防突变的工程做法）

1. 先只生成**基准帧**：`front_0`、`back_0`、`normal_0`、`excite_0`、`tired_0`、`endscreen`。
2. 之后每一帧都以**同组前一帧 + 基准帧**作为参考图，用"只改姿态/只改眉眼嘴"的增量提示词生成，禁止每组重新抽卡。
3. 每生成一帧就记录其视角、趾数、特征到 `oc_profile.md`，后续帧必须显式复述这些固定项。
4. 全部生成后运行 `validate.py`：它会对未去背的白底方块、UI 装饰被改、相邻帧轮廓面积突变、质心大幅位移（疑似换边/换视角）判 FAIL，对平均色突变判 WARN。**程序只能发现"突变"，不能判定解剖是否合理**，C1/C2/C5/C10 仍需人工或 AI 目检。
5. 目检不通过 → 只重画有问题的那几格，重新 `build_sheet.py`，不要整组重来。

## 6. 交付前自检清单

- [ ] 11 个爪格是同一只/同一双固定的脚，左右未翻转
- [ ] 趾数、爪垫、饰品、配色在所有爪格一致
- [ ] 前爪 0→5 是一个连贯下落动作，后爪 0→4 是连贯加压
- [ ] 污渍与压扁程度随帧号单调增加
- [ ] 12 个 ego 表情是同一张脸，normal 与 excite 成对
- [ ] tired 两帧只差眨眼/嘴部微小幅度
- [ ] 每格背景透明，四角无白块，主体未越界
- [ ] 装饰区（白框/棋盘格/灰条/影子小格）与官方底板逐像素一致
- [ ] 三个保留空白格为空
- [ ] `validate.py` 无 FAIL

## 首版复用白名单（C 档，8 张必生）

首版只生成 `front_0` / `front_3` / `front_5` / `back_0` / `normal_1` / `normal_3` /
`normal_5` / `endscreen`，其余 18 格由 `build_sheet.py` 按 `REUSE_MAP` 复制同组基准帧。

**允许复用**（官方模板中本就近重复，或出现频率极低）：

- `front_1` / `front_2` ← `front_0`（空中段恒定，只在触地时切换一次）
- `front_4` ← `front_5`（地面高压段恒定）
- `back_1..4` ← `back_0`（后爪全程同图）
- `normal_0` / `normal_2` ← `normal_1`；`normal_4` ← `normal_5`
- `excite_*` ← 对应 `normal_*`；`tired_0/1` ← `normal_1`

**禁止复用**：

- 不得跨"前爪/后爪"复用（违反 C5 的透视与同源要求）。
- 不得用镜像、翻转或程序化插值制造"另一只脚"或中间姿态（违反 C1/C2/C4）。
- 不得把 `endscreen` 复制进任何 160×256 / 128×128 角色格。

**已知首版损失**（导入后主动询问用户是否补画）：兴奋表情反馈、疲惫眨眼动画、
后爪压力变化、表情过渡细节。补齐方式是把对应 `<cell>.png` 放进 `frames/` 重新合成，
单格文件优先于复用映射，无需改配置。
