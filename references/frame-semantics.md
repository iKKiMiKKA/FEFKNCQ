# 帧语义与动作连贯性约束（防突变规范）

本文件是逐格提示词的**语义基准**。图像模型最容易犯的错不是画得不像，而是 26 格之间
左右脚互换、视角跳变、趾数变化、污渍忽有忽无、表情变成另一张脸。以下约束必须原样并入
每一条生成提示词，并在生成后逐条复核。

## 1. 前爪 6 帧：同一只脚的一次完整下落

定义一只**固定的脚**（例如：角色自己的左脚，脚尖朝画面左侧），全部 6 帧必须是这只脚在
同一条时间线上的连续姿态，不是 6 张不同的脚。

| 帧 | 姿态 | 允许的变化 |
|---|---|---|
| `front_0` | 侧视、脚跟抬起、脚掌离地最高，脚尖朝左；必须看到完整脚底（穿鞋时露鞋底、戴手套时露手套掌面） | 基准帧 |
| `front_1` | 同一只脚下落，脚掌转向观众（可见脚底/脚趾），略低于帧 0 | 只增加旋转/高度变化 |
| `front_2` | 继续下落，脚掌更正对观众、更接近地面 | 只继续同一方向的旋转 |
| `front_3` | 已触地，转为正面/俯视压平的脚，脚趾朝左，轮廓最舒展 | 触地压平 |
| `front_4` | 同一只脚继续加压，脚掌更扁、趾端更贴地 | 只增加压扁程度 |
| `front_5` | 最大压力，脚掌最扁，趾缘/脚底出现最多污渍 | 只增加污渍与压扁 |

## 2. 后爪 5 帧：同一双脚的另一只（远景）

`back_0..4` 是**同一只后脚**随压力递增的 5 个状态：从不施压到完全压实。
与前爪共享：左右约定、趾数、趾形、指甲/爪垫形状、毛色/肤色、花纹、光照方向、线条粗细。
差异只允许：透视略小、略淡（远景），以及随压力单调增加的压扁与污渍。

**单主体 / 无后腿形态特例**：若 OC 是屁股、蛞蝓/史莱姆、或其他无后腿的单一椭圆下踩体，
则整个后爪组不绘制、留空——只画前爪 `front_*` 作为唯一的下踩主体。生成时跳过 `back_0`，
合成加 `--empty back`，后爪 5 格输出透明且免报 must-generate 缺失（此时首版必生为 9 张）。

## 3. 表情 14 帧：同一张脸，只动眉眼嘴

| 组 | 完整 14 帧设计语义（补图时） | 首版 9 帧实际 |
|---|---|---|
| `normal_0` | 最低 ego：平静/略困/无情绪 | 平静脸 1，开局基准（必生） |
| `normal_1` | 略微注意 | 平静脸 2（必生；先采用 `normal_5` 的高档平静设计占位） |
| `normal_2` | 轻度兴趣、嘴角微扬 | 复用 `normal_1` |
| `normal_3` | 愉悦、眼睛更亮 | 复用 `normal_1` |
| `normal_4` | 明显满足、得意 | 复用 `normal_1` |
| `normal_5` | 最高 ego：陶醉/眯眼满足 | 复用 `normal_1`（其设计暂被 `normal_1` 借用，补细节时移回） |
| `excite_0` | 与 `normal_0` 同一张脸的"刚击杀"兴奋版：眼睛睁大、眉毛上扬、张嘴笑 | 兴奋脸 1（必生，区别于平静脸） |
| `excite_1` | 同一张脸、更兴奋一档（ego 1） | 兴奋脸 2（必生；先采用 `excite_5` 的最高档设计占位） |
| `excite_2` | 同一张脸、最高档兴奋（ego 2） | 复用 `excite_1` |
| `excite_3` / `excite_4` / `excite_5` | ego 3/4/5 的兴奋版 | 复用 `excite_1` |
| `tired_0` / `tired_1` | 体力耗尽的两帧交替：疲惫、喘气、半睁眼；两帧之间只允许**眨眼/嘴部幅度/头部位移几像素**的微小差别，不得换表情、换角度 | 两格都复用 `normal_0` |

`endscreen`：256×128 横幅，画角色与小人（tinies）的收尾画面，作为结算页顶部图；
可以有背景（此格允许不透明），但不得含文字、边框、UI。

**首版档位分配（每列两档）**：平静列 `normal_0`（平静1）/`normal_1`（平静2），
兴奋列 `excite_0`（兴奋1）/`excite_1`（兴奋2）；`normal_2..5` 复用 `normal_1`、
`excite_2..5` 复用 `excite_1`，`tired_0/1` 复用 `normal_0`。`normal_1`/`excite_1`
目前借用 `normal_5`/`excite_5` 的高档设计作占位，补细节时把这两张移回 F11/F12，
再为 F03/F04 重生成中度表情。
`validate.py` 的 `expression:normal-reuse`（`normal_0`/`normal_1` 相同）是 **WARN**；
`expression:kill-ego`（兴奋帧等于平静帧）会判 **FAIL**。

## 4. 连贯性硬约束（必须写进每条提示词）

- **C1 同一只脚（含鞋袜/手套）**：26 格中脚的左右、趾数/趾序/爪垫（裸露时）、**鞋袜或手套的款式、颜色、鞋底纹路与饰物**、疤记、配色、线宽、阴影方向全部固定。禁止左右翻转、禁止换脚、禁止增删脚趾；**禁止把穿鞋/戴手套的参考图改成光脚/裸手，禁止中途脱掉或换款**。
- **C2 视角单调且必须有变化**：前爪 0→2 是"抬起（**必须露完整脚底；穿鞋时露鞋底、戴手套时露手套掌面**）→转掌→下落"，3→5 是"触地→加压→最大压力"。**肉垫/掌垫只在脚底转向观众时可见：`front_0/1/2` 可露，`front_3/4/5` 脚底朝下贴地时只能看到脚背/脚侧/脚跟，肉垫完全不可见；`back_*` 同理（C12）**。三张必生帧 `front_0/3/5` 必须有可量化的轮廓差异（像素差异 ≥10%），禁止三张都画成同一个侧视脚掌朝下；也禁止序列中途从侧视突然跳成俯视再跳回；后爪同理。
- **C3 压力单调**：压扁程度、污渍/贴纸数量与面积随帧号**只增不减**（穿鞋/戴手套时为鞋底泥痕、手套掌面磨痕）；`front_5` 轮廓面积不得小于 `front_3`（压扁应更宽更扁，不是更瘦）。禁止污渍在低压力帧出现、高压力帧消失。
- **C4 姿态幅度递减**：相邻两帧的姿态差应小且方向一致；不得出现"前爪帧 2 还是脚底朝上、帧 3 突然变成侧面全脚掌"这类断崖。
- **C5 前后爪同源**：后爪必须与前爪**同一视角、同一趾序/指序、同一款鞋袜/手套与腕饰**，只做整体缩小 10–15% 与降低饱和度/不透明度作为远景；`back_0` 轮廓覆盖率不得低于 `front_0` 的 60%。不得换成正面/俯视、换一款鞋/手套、另一物种或另一只形状不同的脚（手模式为手）。
- **C6 表情只动眉眼嘴**：耳形、脸型、发型、瞳色、项圈、斑点、妆容固定。禁止换头、换角度、换画风。
- **C7 excite 与 normal 成对**：`excite_N` 必须是平静脸 `normal_0` 的"同一时刻更兴奋"（同一角色、只改眉眼嘴），不是重新画一张脸。
- **C8 tired 两帧微差**：只允许眨眼级差异，禁止突变。
- **C9 实体肢体与边界**：每格透明背景（或纯色底由脚本去背）、不越格、不画边框/文字/投影/背景板；
  **腿/手臂必须是有实体填充的柱状肢体并延伸到格子顶边被裁断，禁止只画两条轮廓线或空心透明腿**，
  所有爪格顶部 30% 区域不透明覆盖率 ≥10%；表情格与横幅主体居中，**爪格不居中**（见 C11）。
- **C10 手与脚的分工**：仅提供手部参考图且用户**未**要求用手时（模式 C），手部图只借线条、
  配色、指甲/饰物风格，不得把手掌当成脚的解剖依据；**用户明确说"用手"时切换到手模式
  （模式 D）**，按真正的手生成，不再限定为脚，见下方「手模式」。
- **C11 贴格底**：11 个爪格的脚掌（手模式为手掌）最底部像素必须紧贴格子底边 `y=255`。
  提示词要求 AI 原始图留白 ≤2px；脚本裁剪透明边并底对齐后成品留白为 2px，
  `validate.py` 的 `ground:*` 放行到 6px（容忍手工调整）。
  游戏按爪格底边对齐 `paw_y`，碰撞只看 `paw_y` 与 `floor_y=228`，不读取图片内容；
  格底留白会造成"脚还悬空、小人却已被判定踩死"。官方底板触地帧留白为 0px。
  禁止在脚下（手下）画地面、影子或透明空隙，禁止把整只脚/手居中摆放。

### 手模式（模式 D，用户明确要求用手时启用）

- 游戏只按坐标切片、不识别语义，因此 11 个爪格可以全部画手；坐标、切帧、C11 贴底边
  与 `validate.py` 全部不变。
- 画**真正的手**（或参考图里的**同款手套**）：裸露时固定五指、指序、指甲、掌纹、掌根、手腕；
  戴手套时固定手套款式、材质、掌心缝线/压纹与腕饰，五指/掌纹只在裸露可见时才约束。
  禁止把脚趾/脚跟/爪垫/脚掌结构套到手上，也禁止画成"长了脚趾的手掌"。
  **不得为了露掌面而脱掉手套改成裸手**，`front_0` 的"露掌面"改为露手套掌面。
- 动作时间线照旧：`front_0..2` 抬手→转掌→下落，`front_3..5` 触地→加压→最大压力；
  `back_0..4` 是同一角色另一只手（远景略小、略淡），不得一只手一只脚混用。
- C1/C2/C3/C4/C5 全部按手等价执行：同一只手、左右固定、指数与指甲不变、掌面污渍只增不减。
- 提示词替换表与 `{{FOOT_FIXED}}` 的填法见 `references/prompts.md`；首版 10 张必生格、
  复用映射、PNG/ZIP 交付流程完全不变。肉垫/掌垫规则同样适用：抬起可见，贴地不可见。

## 5. 生成策略（防突变的工程做法）

1. 首版按 `references/prompts.md` **生成 10 张必生帧**：`front_0`、`front_2`、`front_3`、`front_5`、
   `back_0`、`normal_0`、`normal_1`、`excite_0`、`excite_1`、
   `endscreen`；其余 16 格由 `build_sheet.py` 按 `REUSE_MAP` 复用同组基准帧
   （详见文末「首版复用白名单」）。
2. 用户确认补细节后，新增的每一帧都以**同组前一帧 + 基准帧**作为参考图，
   用"只改姿态/只改眉眼嘴"的增量提示词生成，禁止每组重新抽卡。
3. 每生成一帧就记录其视角、趾数、特征到 `oc_profile.md`，后续帧必须显式复述这些固定项。
4. 合成后运行 `validate.py`：除原有的 `chrome:*` / `plate:*` / `ground:*` /
   `continuity:*` 外，还会检查 `leg:*`（空心腿，FAIL）、`top:*`（腿没到顶边）、
   `pose:*`（必生爪帧姿态无差异）、`pressure:*`（压扁反向）、`back:*`（前后爪不同源）、
   `expression:normal-reuse`（`normal_0`/`normal_1` 相同，WARN）、`expression:kill-ego`
   （兴奋帧等于平静脸，FAIL）、`expression:fast-pass`（后期复用损失，WARN）。
   **程序只能发现几何与统计异常，不能判定"脚底画得对不对 / 是不是同一只脚 /
   有没有擅自脱掉鞋或手套"**，C1/C2/C5/C10 仍必须人工或 AI 目检。
5. 目检不通过 → 只重画有问题的那几格，重新 `build_sheet.py`，不要整组重来。

## 6. 交付前自检清单

- [ ] 11 个爪格是同一只/同一双固定的脚（手模式为同一只/同一双手），左右未翻转
- [ ] 每格脚掌最底部紧贴格子底边，`validate.py` 无 `ground:*` FAIL（游戏中脚不会悬空）
- [ ] `front_0` 能看到完整脚底（穿鞋为鞋底、戴手套为手套掌面），`front_0/2/3/5` 四张姿态明显不同（`pose:*` 无 WARN）
- [ ] `front_5` 比 `front_3` 更宽更扁、污渍最多（`pressure:*` 无 WARN）
- [ ] 后爪与前爪同视角、只缩小 10–15%（`back:*` 无 WARN）
- [ ] 腿/手臂实体填充并延伸到顶边，不是空心描边（`leg:*` 无 FAIL、`top:*` 无 WARN）
- [ ] 平静列做出两档 `normal_0`/`normal_1`（`expression:normal-reuse` 无 WARN）
- [ ] 兴奋帧 `excite_0`/`excite_1` 明显不同于平静脸（`expression:kill-ego` 无 FAIL）
- [ ] 肉垫/掌垫只在抬起帧（`front_0/1/2`）可见，触地/加压/远景帧不露肉垫（C12）
- [ ] 参考图穿鞋/戴手套时，11 格都是同款鞋/手套，没有变成光脚/裸手或中途换款
- [ ] 已把首版复用损失（后期表情不升级、击杀无反馈等）告知用户（`expression:fast-pass` 为预期 WARN）
- [ ] 趾数/掌纹（裸露时）、鞋袜/手套款式与饰品、配色在所有爪格一致
- [ ] 前爪 0→5 是一个连贯下落动作，后爪 0→4 是连贯加压
- [ ] 污渍与压扁程度随帧号单调增加
- [ ] 12 个 ego 表情是同一张脸，normal 与 excite 成对（平静 1/2、兴奋 1/2 各成对）
- [ ] tired 两帧只差眨眼/嘴部微小幅度
- [ ] 每格背景透明，四角无白块，主体未越界
- [ ] 装饰区（白框/棋盘格/灰条/影子小格）与官方底板逐像素一致
- [ ] 三个保留空白格为空
- [ ] `validate.py` 无 FAIL

## 首版复用白名单（C 档，10 张必生）

首版生成 `front_0` / `front_2` / `front_3` / `front_5` / `back_0` / `normal_0` / `normal_1` /
`excite_0` / `excite_1` / `endscreen`，其余 16 格由
`build_sheet.py` 按 `REUSE_MAP` 复制同组基准帧。**表情每列两档，后期复用第二档**。

**允许复用**：

- `front_1` ← `front_0`（空中段恒定，只在触地时切换一次；`front_2` 已必生，独立绘制下落末尾帧）
- `front_4` ← `front_5`（地面高压段恒定）
- `back_1..4` ← `back_0`（后爪全程同图）；单主体无后腿形态整体省略后爪，合成加 `--empty back`
- `normal_2..5` ← `normal_1`（无击杀时沿用第二档平静脸）
- `excite_2..5` ← `excite_1`（后期击杀沿用第二档兴奋脸）；
  `tired_0/1` ← `normal_0`

**禁止复用**：

- 不得跨"前爪/后爪"复用（违反 C5 的透视与同源要求）。
- 不得用镜像、翻转或程序化插值制造"另一只脚"或中间姿态（违反 C1/C2/C4）。
- 不得把 `endscreen` 复制进任何 160×256 / 128×128 角色格。

**已知首版损失**（导入后主动询问用户是否补画，用户提出再加图）：表情只做两档、中间档
未细分（`normal_1`/`excite_1` 暂用高档设计占位）、疲惫眨眼动画、抬爪/加压/后爪压力渐变。
补齐方式是把对应 `<cell>.png` 放进 `frames/` 重新合成，单格文件优先于复用映射。
