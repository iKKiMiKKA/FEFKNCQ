# 示例图编号对照表

编号按**区域 + 从左到右、从上到下**的图位顺序。可用 `scripts/make_numbered_map.py`
在本地生成带编号的标注图（该图含上游像素，不进仓库）。

- `P` = 爪格（160×256），`F` = 表情格（128×128），`E` = 结算横幅
- `U` = UI 装饰（不重画），`X` = 保留空白格（永不采样）

## 爪区（左侧 4 列 × 3 行）

| 编号 | 坐标 | 帧名 | 出现时机 | 频率 |
|---|---|---|---|---|
| P01 | (0,0) | `front_0` | `paw_state=0`，爪在屏幕上半，抬起最高 | 高 |
| P02 | (160,0) | `front_3` | 触地、压力≈0 | 高 |
| P03 | (320,0) | `back_0` | 后爪压力 <0.125 | 高 |
| P04 | (480,0) | `back_3` | 后爪压力 0.625–0.875 | 低 |
| P05 | (0,256) | `front_1` | `paw_state=1`（120 < `paw_y` ≤ 180） | 高 |
| P06 | (160,256) | `front_4` | 触地压力 >0.25，或爪被小人顶住 | 中 |
| P07 | (320,256) | `back_1` | 后爪压力 0.125–0.375 | 中 |
| P08 | (480,256) | `back_4` | 后爪压力 ≥0.875（几乎按到屏幕底） | 极低 |
| P09 | (0,512) | `front_2` | `paw_state=2`（180 < `paw_y` < 228） | 高 |
| P10 | (160,512) | `front_5` | 触地压力 >0.5，最大压扁 | 中低 |
| P11 | (320,512) | `back_2` | 后爪压力 0.375–0.625 | 中 |
| X01 | (480,512) | 空白 | 后爪第 6 帧预留 | 永不 |

⚠️ **图位编号不等于动画顺序**。前爪动画顺序：
`P01 → P05 → P09 → P02 → P06 → P10`；后爪：`P03 → P07 → P11 → P04 → P08`。

压力来自鼠标纵向位置：`pressure = (my*2 - 240) / 240`（内部画布高 240）。
>0.25 → 鼠标在 62.5% 以下；>0.5 → 75% 以下；≥0.875 → 93.75% 以下。

## 表情区（右侧 2 列 × 8 行）

| 编号 | 坐标 | 帧名 | 出现时机 |
|---|---|---|---|
| F01 | (768,0) | `normal_0` | 常态，ego 等级 0 |
| F02 | (896,0) | `excite_0` | 等级 0 + 刚获得 ego 的 0.5 秒 |
| F03 | (768,128) | `normal_1` | ego 等级 1（1000–1999） |
| F04 | (896,128) | `excite_1` | 等级 1 + 兴奋 |
| F05 | (768,256) | `normal_2` | ego 等级 2 |
| F06 | (896,256) | `excite_2` | 等级 2 + 兴奋 |
| F07 | (768,384) | `normal_3` | ego 等级 3 |
| F08 | (896,384) | `excite_3` | 等级 3 + 兴奋 |
| F09 | (768,512) | `normal_4` | ego 等级 4 |
| F10 | (896,512) | `excite_4` | 等级 4 + 兴奋 |
| F11 | (768,640) | `normal_5` | ego 等级 5（最高档） |
| F12 | (896,640) | `excite_5` | 等级 5 + 兴奋 / `finished` 时 |
| X02/X03 | (768/896,768) | 空白 | 等级 6 预留，默认永不出现 |
| F13 | (768,896) | `tired_0` | `exhausted`（体力耗尽）两帧交替 |
| F14 | (896,896) | `tired_1` | 同上，另一帧 |

等级 = `floor(ego_climb / 1000)`，`ego.levels = 6`，`ego_climb` 以约 2000/秒追向 `ego_val`。
每次击杀约 `5 + floor(strength*2)` 点 ego，逃脱扣回，另有 2.5/秒被动衰减；
`ego_val ≥ 5999` 触发 `finished`，约 1 秒后进结算并隐藏头像 HUD。
因此 F09–F12 只出现在长时间干净通关的后段，F13/F14 属于失误状态，X02/X03 默认永不出现。

⚠️ **首版的表情策略**：无击杀时（`normal` 列 F01/F03/F05/F07/F09/F11）复用同一张平静脸
`normal_0`，头像不随 ego 升级；击杀（`excite` 列）在 ego 0/1/2（F02/F04/F06）三档独立、
明显变化，`excite_3/4/5`（F08/F10/F12）复用 `excite_2` 最高档，后期击杀仍有反馈；
`tired_0/1` 同图 → 疲惫无眨眼。想让 normal 也随 ego 升级，按 `references/prompts.md`
第 9 节补 `normal_1/2` 即可。

## 其余格位

| 编号 | 坐标 | 名称 | 出现时机 |
|---|---|---|---|
| E01 | (0,768,256×128) | `endscreen` | 结算画面顶部横幅，每局一次 |

| U02 | (640,128) | `portrait_bg` | HUD 棋盘底，常显 |
| U03 | (640,256,128×32) | `intro_flag` | 开场角色名底条 |

| U05 | (751,998,4×21) | `shadow_mid` | 爪影中段平铺 |

合计：26 个角色格 + 5 个装饰格 + 3 个空白格 = 34 个格位。

## 首版（C 档）必生与复用

见 `scripts/layout.py` 的 `MUST_GENERATE` 与 `REUSE_MAP`。
首版生成 9 张：`P01(front_0)`、`P02(front_3)`、`P10(front_5)`、`P03(back_0)`、
`F01(normal_0)`、`F02(excite_0)`、`F04(excite_1)`、`F06(excite_2)`、`E01(endscreen)`；
其余 17 格由 `build_sheet.py` 自动复制同组基准帧。
**补细节不需要改配置**：把 `<帧名>.png` 放进 `frames/` 重新合成即可自动覆盖复用。
