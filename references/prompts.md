# 逐格生图提示词模板（给豆包 / 即梦 / 百度搭子等图像模型）

**核心原则：一次只生成一格，绝不要求模型输出整张 1024×1024 精灵表。**
整表由 `scripts/build_sheet.py` 按坐标合成，模型只负责"这一格里画什么"。

## 1. 占位符

| 占位符 | 内容 |
|---|---|
| `{{OC_DESC}}` | `oc_profile.md` 里的角色长相、配色、物种、画风 |
| `{{FOOT_FIXED}}` | 固定脚部特征：左右、趾数、趾序、爪垫、指甲/鞋袜、记号、描边色 |
| `{{FACE_FIXED}}` | 固定脸部特征：脸型、耳形、瞳色、发型、项圈/斑点、描边色 |
| `{{STYLE}}` | 线条粗细、上色方式、阴影方向、是否与官方示例同画风 |
| `{{REF}}` | 本组基准帧与/或前一帧（作为参考图上传给模型） |

## 2. 通用前缀（每条提示词都要带上）

```
为 2D 手绘游戏生成【单张独立素材图】，只画一个主体，居中，占画面约 80%，不要越出画面。
角色设定：{{OC_DESC}}。画风：{{STYLE}}。
背景：纯透明 PNG；若无法输出透明，请用纯白色（#FFFFFF）平铺背景，主体外不要有任何渐变、阴影或环境。
严格禁止：文字、水印、边框、圆角框、UI 元素、投影、多余人物、多余肢体、第二只脚、镜像翻转、随机花纹变化。
构图比例：爪格为竖版 5:8，表情格为正方形 1:1，结算横幅为横版 2:1。
参考图 {{REF}} 只用来对齐长相与上一帧姿态；禁止改变 {{FOOT_FIXED}} / {{FACE_FIXED}} 中任何固定特征。
```

## 3. 通用负面提示词

```
文字, 字母, 水印, 边框, 背景板, 立体 3D, 照片质感, 多只脚, 左右翻转, 趾数变化,
新增饰品, 换脸, 换发型, 换瞳色, 换画风, 突然的视角切换, 突然出现的污渍,
突然消失的污渍, 血腥特写, 越界裁切, 白底方块, 灰色棋盘格
```

## 4. 连贯性固定句（每条逐格提示词的结尾都要追加）

```
必须与同组相邻帧构成同一动作的连续帧：同一只脚/同一张脸、固定左右与视角、
{{FOOT_FIXED}} / {{FACE_FIXED}} 完全不变；只允许本次指定的姿态或表情变化；
压扁程度与污渍只增不减；不得突变。
```

## 7. 横幅提示词（1 条）

`endscreen.png`：`{{OC_DESC}} 与小人（tinies）在一起的横版收尾插画，用作游戏结算页顶部横幅；
横版 2:1，主体居中，可以有背景色（此格允许不透明），但禁止任何文字、边框、UI、水印。`

## 8. 生成批次与命名

1. **第一批（基准帧）**：`front_0`、`back_0`、`normal_0`、`excite_0`、`tired_0`、`endscreen`。
2. **第二批起**：每格把"同组前一帧 + 基准帧"作为参考图上传，用增量提示词生成；禁止重新随机抽卡。
3. 输出统一命名为 `frames/<cell>.png`，例如 `frames/front_3.png`。尺寸不精确没关系，
   `build_sheet.py` 会等比缩放并居中贴入目标格。
4. 若模型不接受透明输出，统一指定纯白底，并在合成时用 `--bg white`；不要混用多种底色。

## 9. 与脚本的衔接

```
python scripts/build_sheet.py --frames frames/ --base generic.png --out custom.png --bg auto
python scripts/validate.py --sheet custom.png --base generic.png --report custom.report.json
```

`validate.py` 的 FAIL 必须修完再导入；WARN 需要逐条目检（尤其"centroid jump"与"flat background"）。
